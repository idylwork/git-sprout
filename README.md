# GitSprout

A simple Git client with essential features, as quick to use as the command line.

macOS 向けの Git クライアントです。細かい操作は CLI に依存し、よく使われる操作や、ファイル差分などの GUI の強みが生きる部分に絞って表示します。

## できること

- 変更の確認・ステージ
- ファイル単位・ハンク単位・行単位のステージと破棄、コミット
- コミット履歴、ファイルごとの変更履歴の閲覧
- ブランチの作成、切り替え、マージやリベースなどの操作
- リモートとの前後関係に応じたプッシュとプル
- スタッシュ
- コミットメッセージ、パス、ファイル内容の検索
- ターミナルによる操作
- 実験的な機能としてコミットメッセージの提案など (Apple Intelligence が利用できる場合のみ)

## 対応しないもの
- タグ
- チェリーピック
- インタラクティブなリベース
- サブモジュール・サブツリー
- ワークツリー

対象外の操作は、組み込みターミナルから実行してください。

## 動作環境

- macOS 15 以降
- git コマンドをシステムにインストール
